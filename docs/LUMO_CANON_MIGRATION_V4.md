# Migración al canon visual v4

## Resultado

El Character Design aprobado pasa de ser material consultivo a ser la fuente maestra ejecutable del proyecto. La interfaz, los perfiles, los prompts y las validaciones leen ahora activos derivados directamente de ese archivo.

## Incompatibilidades corregidas

| Elemento anterior | Canon v4 |
|---|---|
| Lumo como estrella 2D de cinco puntas | Criatura luminosa 3D redondeada con antenas y corazón cian |
| Tuno como bellota de madera | Mapache inventor con gafas y mono de trabajo |
| Pompón como criatura de musgo y semillas | Criatura morada, redonda y peluda |
| Nara con flor amarilla desmontable | Criatura de hojas con corona y falda vegetal |
| Nublo con orejas redondas y mochila grande | Criatura nocturna de orejas triangulares, farol y cola de niebla |
| Avatares abstractos en la biblioteca | Retratos reales recortados del Character Design |
| Referencias v3 dañadas o incompletas | Activos PNG v4 íntegros con checksum de la fuente |
| Generación pagada bloqueada sin plan | Presupuesto versionado, canon gate y reserva de emergencia |

## Política de material heredado

Los vídeos ya pagados pueden reutilizarse cuando superan una revisión visual contra el canon. Las hojas o imágenes que contradigan el diseño quedan marcadas como retiradas. No se eliminan del historial para conservar trazabilidad, pero las validaciones impiden que vuelvan a entrar en un paquete de generación.
